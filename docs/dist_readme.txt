RedBlue Lab v1.3.0 — 使用说明

包含两块数据：中国福利彩票双色球、中国体育彩票超级大乐透。

一、怎么启动
  1) 推荐：双击 RedBlueLab\RedBlueLab.exe（文件夹版，启动最快、最稳）
  2) 单文件版：双击 RedBlueLab-onefile.exe；如果提示
     "Could not create temporary directory"，就改用 单文件版启动.bat
     （它会把临时目录固定到本目录下的 runtime_tmp）

二、双色球（侧栏「双色球」）
  推荐 / 成绩单 / 筛选器 / 历史数据 / 走势图，推荐页右上角「抓取新开奖」增量同步官网。

三、大乐透（侧栏「大乐透」）
  推荐 / 历史数据 / 走势图；推荐页同样有「算法」「注数」「前区和值」和「抓取新开奖」。
  抓取会重新拉取体彩官网 30 页历史并重建数据集，约 30 秒。

四、数据放在哪
  首次启动会把内置的种子数据复制到：
    %LOCALAPPDATA%\RedBlueLab\data\ （不可写时自动退到 exe 同目录 data\）
  分别是 ssq_history.csv / dlt_history.csv 以及 raw\、dlt_raw\ 分页缓存。
  如果之前用过旧版（SSQAdvisor），成绩单和设置会自动迁移过来。
  删掉这个目录再启动，即可恢复到出厂数据集。

五、提醒
  彩票开奖是独立随机事件，任何选号方法都不能提高中奖概率。
  双色球单注 2 元、返还率约 54%；大乐透单注 2 元、返还率约 47%。
  本软件只做历史统计与组合生成，请理性购彩、量力而行。
