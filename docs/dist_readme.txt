RedBlue Lab v2.0.0 — 使用说明



包含八种彩票的历史数据：双色球、快乐8、福彩3D、七乐彩（福彩）

与 超级大乐透、7星彩、排列3、排列5（体彩）。



一、怎么启动

  1) 推荐：双击 RedBlueLab\RedBlueLab.exe（文件夹版，启动最快、最稳）

  2) 单文件版：双击 RedBlueLab-onefile.exe；如果提示

     "Could not create temporary directory"，就改用 单文件版启动.bat

     （它会把临时目录固定到本目录下的 runtime_tmp）



二、福彩（侧栏「福彩」）

  双色球：推荐 / 成绩单 / 筛选器 / 历史数据 / 走势图

  快乐8、福彩3D、七乐彩：各有「推荐」「历史数据」两页

  推荐页右上角「抓取新开奖」增量同步官网，抓完自动重建数据集。



三、体彩（侧栏「体彩」）

  大乐透：推荐 / 历史数据 / 走势图

  7星彩、排列3、排列5：各有「推荐」「历史数据」两页

  体彩抓取会重新拉取官网分页历史并重建数据集，视彩种约 10–80 秒。



四、数据放在哪

  首次启动会把内置的种子数据复制到：

    %LOCALAPPDATA%\RedBlueLab\data\ （不可写时自动退到 exe 同目录 data\）

  形如 ssq_history.csv / dlt_history.csv / kl8_history.csv ……

  以及 raw\、dlt_raw\、kl8_raw\ … 分页缓存。

  如果之前用过旧版（SSQAdvisor），成绩单和设置会自动迁移过来。

  删掉这个目录再启动，即可恢复到出厂数据集。



五、提醒

  彩票开奖是独立随机事件，任何选号方法都不能提高中奖概率。

  各彩种单注 2 元，返还率约 47%–58%（双色球 ~54%、大乐透 ~47%、

  快乐8 选十 ~58%）。本软件只做历史统计与组合生成，请理性购彩。
